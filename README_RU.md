# MaxsgMuss — капча с камерой на Python

Учебный проект по компьютерному зрению для первого курса. Программа выбирает случайный жест, показывает изображение камеры и открывает доступ в своём окне, если жест выполнен правильно.

Интерфейс выполнен в виде панели безопасности: слева находится карточка предпросмотра камеры, справа — карточка задания, прогресс удержания, таймер и цветной индикатор результата. В шапке отображается состояние камеры: подключение, работа, остановка или завершение проверки.

**Вся программа находится в одном файле `MaxsgMuss.py`.** Интерфейс использует `customtkinter`: он добавляет скруглённые карточки, светлую и тёмную темы и аккуратные кнопки. Файлы `requirements.txt` и эта инструкция нужны только для удобства. Отдельно скачивать модель нейросети не нужно. Интернет требуется при установке библиотек; сама программа работает локально.

## Обновление интерфейса и исправление камеры

Зависание на «Подключение камеры…» вызывали старые вызовы `.config()` и параметры `fg` после перехода с Tkinter. В CustomTkinter 5.2.2 нужно применять `.configure()` и `text_color`. Ошибка происходила до открытия устройства. Все такие вызовы исправлены: [справочник CTkLabel](https://customtkinter.tomschimansky.com/documentation/widgets/label/). Для вывода видео теперь используется `CTkImage`: [официальная документация](https://customtkinter.tomschimansky.com/documentation/utility-classes/image/).

Что изменилось:

- Приложение называется **MaxsgMuss** в шапке и заголовке окна.
- После успешной проверки видео заменяется тёмным зелёным фоном с галочкой и надписью «Проверка пройдена». Кадр камеры удаляется из объектов предпросмотра.
- Убраны квадратные участки за скруглёнными карточками, выровнены блоки и отступы.
- Окно можно растягивать; начальный размер учитывает экран и масштаб Windows.
- Кнопка «Повторить попытку» закреплена снизу. В низком окне содержимое задания прокручивается отдельно от кнопок.
- Камеру 0, 1 или 2 можно выбрать прямо над предпросмотром.
- В Windows последовательно пробуются DirectShow, Media Foundation и автоматический выбор OpenCV. Неудачно открытые ресурсы освобождаются.
- Подключение подтверждается первым изображением. Время загрузки не отнимается от 30 секунд попытки.
- Ошибка видна прямо в окне; старый кадр скрывается, кнопка повтора остаётся доступной.
- Индикатор LIVE гаснет после остановки камеры. Сохранены семь жестов и комментарии в коде.
- В шапке есть переключатель тёмной/светлой темы; сочетание цветов меняется без перезапуска камеры.
- При подключении и после успеха работают лёгкие анимации через `after`, поэтому окно остаётся отзывчивым.
- Добавлены горячие клавиши: `R` — новая попытка, `T` — тема, `Space` — старт после остановки, `Esc` — выход.

### Темы и горячие клавиши

Тему можно менять переключателем в правом верхнем углу или клавишей `T`. Она применяется сразу к карточкам,
кнопкам, шкале прогресса и экрану результата. Анимация ожидания меняет значок подключения, а после успеха
пульсирует зелёная галочка. Клавиши работают даже тогда, когда фокус находится на кнопке или меню камеры.

**Если проект уже установлен:** закройте старое окно, положите `MaxsgMuss.py` в папку проекта и запускайте именно его в терминале VS Code:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe MaxsgMuss.py
```

Если открываете `.exe`, после замены Python-файла пересоберите `.exe`: старый исполняемый файл не обновляется сам.

## Ошибка `Activate.ps1` в PowerShell

Сообщение **«невозможно загрузить файл Activate.ps1, так как выполнение сценариев отключено»** относится к настройкам PowerShell. Оно не означает ошибку капчи. Окружение можно вообще не активировать: команды ниже используют Python прямо из папки `.venv312`.

```powershell
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
.\.venv312\Scripts\python.exe MaxsgMuss.py
```

Если у вас папка называется `.venv`, замените `.venv312` на `.venv`. В архив также добавлен файл `run_MaxsgMuss.bat`: запустите его двойным щелчком, и `Activate.ps1` не понадобится.

Если всё же нужна активация в текущем окне PowerShell, выполните временное разрешение только для этого окна, затем повторите команду:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv312\Scripts\Activate.ps1
```

После закрытия окна PowerShell это временное разрешение исчезает.

## Как запустить в Windows

Нужны обычная веб-камера и **Python 3.12 или 3.11, 64-bit**. Для указанных ниже команд выбран Python 3.12. У MediaPipe 0.10.21 есть готовые сборки для этих версий Python в Windows: [страница выпуска на PyPI](https://pypi.org/project/mediapipe/0.10.21/).

1. Установите Python с [официального сайта Python](https://www.python.org/downloads/windows/). При установке включите Tcl/Tk и IDLE, а также Python Launcher. Если Python уже установлен, командой `py -0p` можно посмотреть доступные версии.
2. Распакуйте архив проекта в папку, например `C:\camera_captcha`. Программу нужно запускать на компьютере, к которому подключена камера.
3. Откройте терминал в этой папке. Например, в адресной строке Проводника напишите `cmd` и нажмите Enter.
4. Выполните команды по очереди:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe MaxsgMuss.py
```

Первая команда создаёт отдельное окружение для проекта, вторая устанавливает библиотеки, третья запускает окно. Активировать окружение отдельно не требуется. Установка выполняется один раз и может занять несколько минут. Для Python 3.11 замените `py -3.12` на `py -3.11`.

При следующих запусках достаточно открыть терминал в той же папке и выполнить:

```bat
.venv\Scripts\python.exe MaxsgMuss.py
```

**Если вы скачали только один Python-файл**, вместо установки из `requirements.txt` используйте:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install mediapipe==0.10.21 opencv-contrib-python==4.11.0.86 numpy==1.26.4 pillow==11.3.0 customtkinter==5.2.2
.venv\Scripts\python.exe MaxsgMuss.py
```

Для запуска в PyCharm или VS Code выберите интерпретатор `.venv\Scripts\python.exe`, затем запускайте `MaxsgMuss.py` обычной кнопкой Run. Если в шапке написано `GESTUREGUARD`, открыта старая копия.

## Сборка Windows `.exe`

После установки зависимостей можно собрать один файл, который запускается без Python:

```bat
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name MaxsgMuss --collect-all mediapipe --collect-all cv2 --collect-all customtkinter MaxsgMuss.py
```

Сборку выполняйте на Windows для Windows; готовый `.exe` проверьте на целевом компьютере. Готовая программа появится в `dist\MaxsgMuss.exe`. Параметр `--collect-all customtkinter` нужен, чтобы в `.exe` попали файлы темы и скруглённых элементов. Передачу другому пользователю можно выполнять одним файлом `MaxsgMuss.exe`; Python и библиотеки на его компьютере не требуются. После изменения кода `.exe` нужно собрать заново.

## Как пользоваться

1. Откройте программу. Камера подключается автоматически, справа появляется случайное задание.
2. Покажите одну кисть целиком, ладонью к камере и пальцами вверх. Обеспечьте равномерное освещение.
3. Выполните нужный жест и удерживайте его **1,5 секунды подряд**. Прогресс отображается полосой.
4. При успехе появляется зелёная карточка **«Доступ открыт»**, индикатор камеры меняется на «Камера выключена». Вместо кадра камеры появляется тёмный зелёный фон с галочкой и надписью **«Проверка пройдена»**. Таймер показывает «Готово».
5. Кнопка **«Пройти ещё раз»** снова закрывает доступ, включает камеру и выбирает другой жест. Во время проверки она называется **«Новое задание»**, после ошибки или истечения времени — **«Повторить попытку»**. Кнопка **«Выйти»** завершает работу.

Горячие клавиши: `R` — новая попытка, `T` — переключение темы, `Space` — начать попытку после остановки,
`Esc` — закрыть окно. Если камера ещё подключается, повторная команда `R` игнорируется до завершения подключения.

На попытку даётся 30 секунд. Если время вышло, доступ остаётся закрыт, камера выключается. Новую попытку можно начать кнопкой «Повторить попытку». Неправильный жест, потеря руки или обнаружение двух рук сбрасывают накопленное удержание.

| Задание | Что показать |
| --- | --- |
| Раскрытая ладонь | Выпрямить указательный, средний, безымянный пальцы и мизинец |
| Знак V | Поднять указательный и средний, согнуть безымянный и мизинец |
| Указательный палец | Поднять указательный, согнуть остальные три |
| Три пальца | Поднять указательный, средний и безымянный, согнуть мизинец |
| Знак рока | Поднять указательный и мизинец, согнуть средний и безымянный |
| Кулак | Сжать четыре пальца; большой палец можно положить сверху |
| Большой палец вверх | Сжать четыре пальца и поднять большой палец |

Для большинства жестов достаточно четырёх пальцев, но в задании «Большой палец вверх» дополнительно проверяется положение большого пальца. Можно использовать левую или правую руку. Боковое положение кисти и сильные повороты не поддерживаются надёжно — это ограничение простого алгоритма.

## Как устроено компьютерное зрение

OpenCV получает кадр камеры. MediaPipe находит 21 точку кисти: запястье, суставы и кончики пальцев. Подготовленная модель MediaPipe уже умеет находить эти точки; обучать свою нейросеть в проекте не требуется. Описание точек и API есть в [документации MediaPipe Hands](https://chuoling.github.io/mediapipe/solutions/hands.html).

Жест определяет наша функция `recognize_gesture()`. Обычно она смотрит на четыре пальца. Для каждого сравниваются вертикальные координаты кончика и среднего сустава:

```python
difference = points[tip - 2].y - points[tip].y
fingers.append(difference > 0)
```

Координата `y` растёт сверху вниз. Если кончик находится выше сустава, разность положительная: в список добавляется `True`, то есть палец поднят. Если ниже — `False`, палец согнут. Небольшая разность считается неопределённым положением и не засчитывается. Так нейросеть решает задачу поиска кисти, а понятные условия на Python — задачу определения жеста.

| Палец | Номер кончика | Номер среднего сустава |
| --- | ---: | ---: |
| Указательный | 8 | 6 |
| Средний | 12 | 10 |
| Безымянный | 16 | 14 |
| Мизинец | 20 | 18 |
| Большой палец | 4 | 3, только для жеста «Большой палец вверх» |

| Жест | Указательный | Средний | Безымянный | Мизинец |
| --- | --- | --- | --- | --- |
| Ладонь | True | True | True | True |
| V | True | True | False | False |
| Указательный | True | False | False | False |
| Три пальца | True | True | True | False |
| Знак рока | True | False | False | True |
| Кулак | False | False | False | False |

Это приближённое правило для кисти пальцами вверх, а не точное измерение углов суставов. Оно может ошибаться при перекрытии пальцев, плохом освещении или наклоне руки.

## Где что находится в коде

В коде есть русские комментарии к настройкам, основным строкам и действиям. Интерфейс построен на `customtkinter`, а обработка камеры и MediaPipe остались прежними. Многострочный текст в самом начале — описание запуска и лицензия; он не выполняется как программа.

| Часть программы | Назначение |
| --- | --- |
| Настройки в начале | Номер камеры, время удержания, срок задания, цвета |
| `GESTURES` | Названия жестов и подсказки |
| `recognize_gesture()` | Определение жеста по координатам |
| `CaptchaApp.__init__()` | Создание окна customtkinter, карточек, надписей и кнопок |
| `open_camera()` | Подключение выбранной камеры и проверка первого кадра |
| `resize_preview()` | Масштабирование изображения с сохранением пропорций |
| `show_placeholder()` | Фон вместо кадра при подключении, ошибке или успешной проверке |
| `set_progress()` | Обновление шкалы удержания и числа секунд |
| `set_status()` | Единое обновление текста и цвета результата |
| `set_camera_badge()` | Обновление индикатора камеры в шапке |
| `set_theme()` и `apply_theme()` | Переключение и применение светлой/тёмной палитры |
| `stop_animations()`, `animate_loading()`, `animate_success()` | Неблокирующие анимации через `root.after()` |
| `new_challenge()` | Сброс результата, случайный выбор и подключение камеры |
| `update_frame()` | Чтение кадра, поиск кисти и показ изображения |
| `check_result()` | Проверка срока задания и длительности удержания |
| `fail()` | Обработка ошибок с закрытым доступом |
| `stop_camera()` | Остановка обновлений и освобождение камеры |
| `close()` | Закрытие окна |
| `if __name__ == "__main__"` | Подключение библиотек и запуск приложения |

`class CaptchaApp` объединяет окно и его состояние. Например, `self.camera` — камера этого приложения, `self.target` — нужный жест, `self.access_granted` — результат проверки. `self` означает текущий объект приложения.

`root.after(30, self.update_frame)` просит Tkinter вызвать обработку следующего кадра примерно через 30 миллисекунд после завершения текущей обработки. Это не гарантия 30 кадров в секунду: скорость зависит от камеры и компьютера. Между вызовами Tkinter обрабатывает кнопки. Для простоты обработка кадра выполняется в том же потоке, поэтому на слабом компьютере окно может кратковременно задерживаться.

`time.monotonic()` измеряет прошедшее время. Если человек изменит системные часы, отсчёт от этого не изменится. Если пауза между обработанными кадрами превысит 0,5 секунды, старое удержание сбрасывается.

## Что можно легко изменить

```python
APP_NAME = "MaxsgMuss" # Название приложения.
CAMERA_INDEX = 0       # Попробуйте 1, если нужна другая камера.
HOLD_SECONDS = 1.5     # Например, 2.0 для двух секунд удержания.
TIME_LIMIT = 30        # Например, 45 для более длинной попытки.
MAX_FRAME_GAP = 0.5    # Допустимая пауза между обработанными кадрами.
```

Время удержания должно быть положительным и меньше времени всей попытки. Для смены оформления достаточно изменить словари `THEMES["dark"]` и `THEMES["light"]` в начале файла. Старые константы цветов оставлены рядом для понятности учебного кода. Для интерфейса требуется дополнительная библиотека `customtkinter==5.2.2`; стандартные Tkinter и ttk входят в Python.

## Что взято из чужого кода

Использован открытый проект [CVZone на GitHub](https://github.com/cvzone/cvzone). Конкретный источник — `cvzone/HandTrackingModule.py`, метод `fingersUp` из версии **1.6.1**. Автор: **Vizdx LLC / Computer Vision Zone**, лицензия MIT, указанная также на [странице выпуска](https://pypi.org/project/cvzone/1.6.1/).

Адаптирована только короткая часть, сравнивающая кончики четырёх пальцев с суставами. В нашем варианте точки используются напрямую, добавлены допуск, проверка положения кисти и сопоставление с семью жестами. Полная лицензия исходного фрагмента сохранена внутри `MaxsgMuss.py`, поэтому она остаётся с программой даже при передаче одного файла. Устанавливать сам CVZone для запуска не нужно.

Прямое чтение страниц `github.com` во время подготовки было недоступно. Исходник и лицензию CVZone прочитали из опубликованного автором архива на PyPI, связанного с тем же GitHub-проектом. Проверенная контрольная сумма архива `cvzone-1.6.1.tar.gz` (SHA-256):

```text
a6bea5834647b6fc52a44d8b4b670f8c88b2d4f0fc56549b4024ce224f0d3979
```

Для подключения камеры и обработки кадров использована справка [MediaPipe Hands на GitHub Pages](https://chuoling.github.io/mediapipe/solutions/hands.html). Исходный проект — [Google AI Edge / MediaPipe на GitHub](https://github.com/google-ai-edge/mediapipe). Окно Tkinter, задания, таймеры и проверка доступа написаны для этого учебного проекта.

## Почему закреплены версии

Для короткого кода использован API `mp.solutions.hands`, доступный в MediaPipe 0.10.21. Это прежний API MediaPipe, поэтому обновлять библиотеку произвольно для этого файла не следует. Модель сложности `1` входит в пакет. Текущий API Hand Landmarker устроен иначе и предполагает отдельный файл модели: [справочник Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker).

OpenCV и NumPy также закреплены для совместимости выбранного набора. Используется только `opencv-contrib-python`; отдельно устанавливать `opencv-python` или его headless-варианты в это же окружение не нужно. У этих пакетов одно имя импорта `cv2`, и авторы рекомендуют выбирать один вариант: [инструкция OpenCV on Wheels](https://pypi.org/project/opencv-contrib-python/4.11.0.86/).

## Если что-то не запускается

| Ситуация | Что сделать |

| `No matching distribution found for mediapipe` | Проверьте, что выбран Python 3.11/3.12, 64-bit. На Python 3.13+ закреплённую версию ставить не следует |
| `No module named cv2`, `mediapipe`, `PIL` или `customtkinter` | Установите зависимости через тот же `.venv\Scripts\python.exe`, которым запускаете файл |
| `module mediapipe has no attribute solutions` | Проверьте закреплённую версию; ваша программа не должна называться `mediapipe.py` |
| Ошибка доступа к камере | Закройте другие приложения с камерой; проверьте доступ к камере для приложений рабочего стола в параметрах Windows |
| Выбрана другая камера | Выберите «Камера 1» или «Камера 2» в меню над изображением; `CAMERA_INDEX` задаёт начальный выбор |
| Всё ещё видно «Подготовка задания» или «CTkLabel» | Запущена старая версия: замените Python-файл; для `.exe` выполните новую сборку |
| Рука найдена, жест не определяется | Покажите кисть целиком, пальцами вверх, избегайте сильного наклона и засветки |
| Прогресс постоянно сбрасывается | Удерживайте жест неподвижно, улучшите освещение, закройте тяжёлые приложения |
| Окно сразу исчезает после двойного щелчка | Запустите файл из терминала, чтобы увидеть сообщение об ошибке |
| Ошибка загрузки DLL или бинарного модуля | Проверьте разрядность Python и используйте новое отдельное окружение с указанными версиями; сохраните полный текст ошибки |

На macOS и Linux принцип тот же: создать окружение через `python3.12 -m venv .venv`, установить зависимости командой `.venv/bin/python -m pip install -r requirements.txt`, затем выполнить `.venv/bin/python MaxsgMuss.py`. Нужна графическая сессия и работающий Tkinter. На Linux системный пакет Tkinter должен соответствовать установленному Python. Работа на этих платформах с живой камерой не проверялась.

## Что означает «безопасность» в этом проекте

Программа демонстрирует проверку случайного задания перед условным доступом. Здесь «Доступ открыт» — состояние и надпись внутри приложения. Программа не разблокирует компьютер и не предоставляет права в другой системе.

Она не устанавливает личность и не доказывает, что перед камерой живой человек. Запись, изображение или подмена видеопотока могут привести к неверному результату, а локальный код может быть изменён. Поэтому это учебный прототип жестовой капчи, не готовая защита сайта, аккаунта или помещения. Удержание уменьшает влияние случайных кадров, но не является проверкой живости.

## Как представить работу на защите

Можно объяснить проект так:

«Я разработал учебный прототип капчи с использованием камеры. OpenCV получает изображение, MediaPipe определяет 21 точку кисти, а алгоритм на Python определяет жест по положению четырёх пальцев. Пользователь получает случайное задание. Если правильный жест удерживается полторы секунды в пределах 30 секунд, программа выводит сообщение “Доступ открыт”. Интерфейс создан на CustomTkinter поверх Tkinter. Часть проверки положения пальцев адаптирована из CVZone с сохранением авторства и лицензии. Проект демонстрирует компьютерное зрение и логику проверки доступа, но не выполняет биометрическую идентификацию».

Перед демонстрацией обязательно проверьте на своём ноутбуке: все семь жестов, неправильный жест, отсутствие руки, две руки, сброс удержания при потере руки, истечение времени, новое задание после успеха и освобождение камеры при выходе.
